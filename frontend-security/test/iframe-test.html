Clickjacking / Framing Security Test

Test Purpose:

This page simulates an external attacker's website attempting to frame the protected /account page in an <iframe> to mount a clickjacking attack.

Expected Secure Result: The embedded frame below MUST fail to render. Modern browsers will refuse to display the document and log the following security violations in the developer console:

  • Refused to display 'http://localhost:3000/account' in a frame because it set 'X-Frame-Options' to 'deny'.
  • Refused to frame 'http://localhost:3000/account' because an ancestor violates the following Content Security Policy directive: "frame-ancestors 'none'".

Verification Note: In vulnerable versions of the application, the account settings card with the red "Delete Account" button would render inside this box without restriction.
